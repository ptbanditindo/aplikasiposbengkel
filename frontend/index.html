Backup & pemulihan database

Seluruh data lokal (pelanggan, unit, nota, stok, pengaturan) ada dalam satu file database.

Pulihkan file database dari perangkat lain saat instalasi baru. Data saat ini akan diganti, tetapi backup keamanan dibuat otomatis sebelum pemulihan.

Backup otomatis Telegram

Belum diatur.

Token Telegram perlu diisi ulang agar backup otomatis berjalan.

Setiap pengiriman berisi satu file database lengkap (semua data) dengan nama rentang tanggal, sehingga tidak ada file terpisah yang tumpang tindih. Butuh koneksi internet. Jika backup harian terlewat (misalnya internet mati), aplikasi langsung mengirimkannya begitu internet tersedia tanpa menunggu jam kirim.
